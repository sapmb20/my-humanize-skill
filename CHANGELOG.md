# Changelog

## v1.0.0 (2026-10-06)

- First release of `my-humanize`, built from Wikipedia's "Signs of AI writing" (retrieved
  2026-10-06; extracted via Chrome after a keyless Firecrawl scrape was refused for credits).
- `SKILL.md`: detect → rewrite → self-audit workflow and a pattern catalog (content, language,
  style, communication residue, leaked markup, edit summaries), plus what human prose does that
  AI avoids, and caveats.
- `references/signs-of-ai-writing.md`: fuller distilled notes, including Wikipedia-specific
  markup, citation, comment, and edit-summary signs and historical indicators.
